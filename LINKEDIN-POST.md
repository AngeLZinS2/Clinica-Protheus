# Postagem para LinkedIn — Clínica Protheus

## Texto pronto para publicar

🏥 **Novo projeto no meu portfólio: Clínica Protheus**

Desenvolvi uma aplicação full stack para organizar a rotina de clínicas, conectando atendimento, gestão e experiência do paciente em um único sistema.

O projeto inclui:

✅ autenticação segura e controle de acesso por perfil

✅ gestão de pacientes, consultas e procedimentos

✅ painel com indicadores operacionais

✅ área exclusiva para pacientes

✅ auditoria de ações importantes

✅ interface responsiva com temas claro e escuro

✅ experiência de login com uma molécula de DNA interativa em 3D

✅ ambiente completo em Docker com PostgreSQL, Flask, React e Nginx

Além da implementação das funcionalidades, trabalhei na arquitetura, validação de dados, segurança da API, acessibilidade e experiência visual. O resultado é uma aplicação pronta para demonstrar um fluxo real de gestão clínica do front ao back.
